# FreshOrder AI — 식재료 수요 예측 및 자동 발주 대시보드

한국디지털콘텐츠학회 양식으로 작성한 「인공지능 기반 수요 예측과 유통기한을 고려한 자동 발주 시스템 설계」 아이템의 웹 데모.

## 핵심 기능

- 과거 소비량으로 MLP(12, 8) 신경망을 학습하여 다음 날 식재료 수요량 예측
- 사용자가 유효 재고량과 안전재고를 입력하면 권장 발주량 계산
- 유통 가능 기간을 반영한 선입선출(FIFO) 재고 시뮬레이션
- 고정 발주와 AI 예측 발주 정책의 구매비, 품절 손실, 폐기비 비교
- CSV 업로드 및 분석 결과 다운로드
- 예제 모드에 90일 재현 가능한 가상 소비량 데이터 기본 제공

## 로컬 실행

Python 3.11 또는 3.12를 권장합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 배포

1. GitHub에서 새 리포지토리를 만듭니다.
2. 이 폴더 안의 `app.py`, `engine.py`, `requirements.txt`, `.streamlit/config.toml`을 업로드합니다 (`.streamlit`은 선택 사항).
3. https://share.streamlit.io/ 에서 GitHub 계정을 연결합니다.
4. `Create app` → `Yup, I have an app` → 리포지토리 및 `app.py` 선택 → `Deploy`.
5. 배포된 `*.streamlit.app` URL을 과제 제출란에 복사합니다.

## 데이터 규격

`date,demand_kg` 헤더가 있는 CSV. 날짜는 `YYYY-MM-DD`, 소비량은 kg 단위 0 이상의 수, 40일 이상 연속된 날짜여야 합니다.

예시:

```csv
date,demand_kg
2026-08-03,26.0
2026-08-04,27.1
```

## 연구 설정 및 주의 사항

- 90일 합성 데이터, 마지막 20일 평가, MLP(12, 8), 보관 가능 기간 3일을 기본으로 구성합니다.
- 기본 비용 가정: 구매비 4,500원/kg, 품절 손실 6,500원/kg, 폐기비 1,200원/kg.
- 비교 정책의 고정 발주량은 학습 기간 소비량 평균에서 반올림하며 변경할 수 있습니다.
- 원본 논문에 기재된 수치(예: MAE 2.53kg, 비용 약 1.4% 감소)를 복제한 것은 아니며, **새롭게 생성한 합성 데이터로 별도 계산**합니다. 조건에 따라 AI 발주의 비용이 더 높을 수도 있습니다.
- 입고 지연 없음, 초기 재고 0, 당일 도착 및 소비, FIFO, 보관 가능 기간은 프로토타입용 가정입니다.
- 데이터와 상태는 실행/접속마다 계산됩니다. 실제 발주 전 재료별 보관 규정, 공급 납기, 수량 단위, 물류 조건 검증이 필요합니다.
